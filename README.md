# Scratch LLMs 
This repo will detail different LLM models and methods that are in use today. Instead of using popular libraries to implement these models and methods I want this repo to contain code from papers and/or books that detail the implementation process from scratch. I will update this repo as I find more papers and/or books that implement many of today's LLM models, Agents, Run-time Environments, Harnesses etc., from scratch.

## Build a Large Language Model (From Scratch)
This repo contains my implementation of the book [Build a Large Language Model (From Scratch) by Sebastian Raschka](https://github.com/rasbt/LLMs-from-scratch). The book details all the steps to build a non-reasoning LLM from scratch.

Currently this repo implements the following chapters of the book:
* [Chapter 3](https://github.com/AdamClarkStandke/TransDiffTemp/blob/main/CodingAttention_ch3.ipynb)
* [Chapter 4](https://github.com/AdamClarkStandke/TransDiffTemp/blob/main/Chapter4_GPTmodel.ipynb)
* [Chapter 5](https://github.com/AdamClarkStandke/TransDiffTemp/blob/main/chapter5_decoding.ipynb)
* [Chapter 7](https://github.com/AdamClarkStandke/TransDiffTemp/blob/main/Chapter7_InstructionFineTuning.ipynb)
